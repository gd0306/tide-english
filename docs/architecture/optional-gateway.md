# 可选托管网关

`server/gateway` 保留账户校验、托管语音、使用计量、分钟账本、商品目录和支付适配代码，以便在独立环境继续开发。默认个人客户端不启用这些能力，邮箱账户服务也不会自动启用它们。

账本必须由服务端管理，客户端的余额显示不是授予使用时间的权限。测试中使用合成的商店身份、价格和凭据，不能作为新应用上架或收款的依据。各项配置、API 和数据库边界见 `server/gateway/docs`。

开启任何托管、试用或购买功能前，需要自己的应用/商店标识、签名、服务端机密、数据备份及回滚版本，并在隔离环境验证合同与权限。新工程重建没有部署这套服务，没有改变当前线上账户服务或生产支付状态。
