# 架构

两个原生客户端独立管理权限、音频、安全存储和学习记录。iOS 的 Domain 是不依赖界面的 Swift 包，Android 的 core 为对应 Kotlin 实现。packages/fixtures 与公共工具检查数据和策略一致性。

模型配置包含服务商、模型及 HTTPS 地址，教学、释义、查询和总结使用所选配置；实时语音按原生能力选择专用音频模型，或者降级为本地识别、同服务商文本生成与系统朗读。更换配置取消旧请求并更新发送同意范围。

模型凭据、邮箱令牌、界面偏好和学习档案分别管理，导出仅含学习数据。server/accounts 处理验证码、会话与账户删除，不同步学习内容。server/gateway 是另一套可选托管与商业服务，默认关闭。

新工程的应用标识、存储命名空间和源码符号独立。源码迁移不读取旧手机沙箱、服务器数据库或凭据；部署模板需要单独配置。
