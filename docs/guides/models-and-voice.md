# 模型与语音

“设置 → 模型与 API 密钥”是统一入口。选择 OpenAI、DeepSeek、GLM、Gemini 或兼容服务，填写对应模型与密钥。自定义服务必须使用支持的 HTTPS 接口。不同服务商及自定义地址的凭据独立，不会把同一密钥自动发给其他地址。

模型可用性取决于服务商、账户和区域，默认值不保证账户已经获得访问。教学、释义、查询和总结使用所选配置。原生实时语音的音频模型可能与可编辑文本模型不同。

DeepSeek/自定义服务使用设备识别、所选模型生成、系统朗读轮流对话。无法使用实时语音时，在支持条件下同服务商降级，否则提供文字。Gemini 长会话到期需重连。

请直接在设备输入密钥，不贴到聊天、issue、源码或日志。备份不含密钥。改变发送对象后应重新查看应用的数据发送说明。
