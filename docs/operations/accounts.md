# 邮箱账户服务

客户端沿用 https://api.gd306.cn 的验证码、会话和删除合同。重建源码不等于部署：没有改变线上服务器、数据库、SMTP或已注册账户。

自建时在 server/accounts 阅读README和deploy/README.md，准备独立PostgreSQL、HTTPS域名、部署账户及SMTP。地址、SMTP授权码、会话密钥通过服务器私密环境配置，不提交.env、不在命令中打印。

先在独立环境执行迁移与合成合同测试，再同步客户端的邮箱API地址。验证有效期、重试、注销不确定状态、健康、数据库就绪、TLS和备份；部署保留回滚镜像。模板镜像不能直接作为新实例已构建镜像使用。

邮箱不负责学习云同步或购买。server/gateway独立部署，不混用数据库及运行权限，不将已有生产库用于新实例初始化。
